Come funziona

  1. Lo smartphone aziendale scatta foto durante le lavorazioni (con targa visibile nel frame).
  2. Syncthing sincronizza automaticamente le foto nella cartella {{ inbox_path }} sul PC.
  3. LYS Hub rileva i nuovi file, invia ogni foto a Claude AI per riconoscere la targa.
  4. La foto viene copiata in {{ fallback_path }}\<TARGA>\ (sempre).
  5. Se la targa corrisponde a una pratica WinCar → copia anche in Pratiche\<n>\Pubblici\Foto\.
  6. Il file originale viene eliminato dall'inbox dopo la copia.

Formato smartphone: configurare fotocamera in JPEG (non HEIC/HEIF). Su Android: formato di default è già JPEG. Su iPhone: Impostazioni → Fotocamera → Formato → Compatibilità massima.
